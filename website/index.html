GET THE NEWEST FEATURES

Enable Beta in ReaPack.

Normal synchronization does not opt you into Beta. Enable pre-releases for the main PsyReaSFX script package first.

  1. Run Extensions → ReaPack → Synchronize packages, then open Browse packages and search for PsyReaSFX.
  2. Right-click the main PsyReaSFX package (PsyReaSFX.lua) and check Enable pre-releases (bleeding-edge).
  3. Right-click again → Versions → choose the newest 0.9.0-beta… (currently beta7.17). Leave Pin current version unchecked; unpin first if needed.
  4. Click Apply, or OK to confirm installation. Once downloads finish, close the old PsyReaSFX window and rerun it from REAPER's Action List.

Local neural similarity requires a separate package: Windows x64 only. Download the complete PsyReaSFX Neural Similarity ZIP (about 42.4 MB, includes model and installers), or install the separate data package through ReaPack. Updating the main script does not install it. Exact installation steps ↓. Without it, similar-sound search uses the built-in 15-feature acoustic method.

AI semantic search: no neural package required. In Settings, create, save and switch named DeepSeek / OpenAI / compatible API presets, each with an independent key and model. Enter runs normal search; the gold AI button runs semantic search. Audio is not uploaded.

Updating the main script does not require rebuilding your libraries. Beta is a testing channel; use Stable for production work when reliability is the priority.

REQUIRED FOR NEURAL RETRIEVAL

Get the model, not just the main script.

One Find Similar Sounds entry, two automatic engines: built-in 15-feature acoustic search needs no download; EfficientAT neural retrieval requires PsyReaSFX Neural Similarity. AI semantic search is separate and needs your API settings, not this package.

Download complete neural ZIP ↗

Windows x64 · Beta 7.17 · about 42.4 MB. Includes executable, model and installers. The standalone Release EXE does not include the model. Choose one installation method below.

Recommended: install inside REAPER

  1. Import the repository URL above, synchronize, then open Extensions → ReaPack → Browse packages.
  2. Search for PsyReaSFX Neural Similarity and select the separate data package, not PsyReaSFX.lua.
  3. Right-click → Enable pre-releases (bleeding-edge) → Versions → latest Beta (currently 0.9.0-beta7.17). Uncheck Pin current version.
  4. Click Apply / OK, wait for downloads, close the old PsyReaSFX window and rerun it. ReaPack installs and updates the model and executable together.

Installed under <REAPER Resource Path>\Data\PsyReaSFX\neural_similarity\.

Alternative: install the complete ZIP

  1. Download the complete neural ZIP and extract all files. Do not run the installer inside the archive.
  2. Double-click Install-NeuralSimilarity.cmd, wait for success, then restart PsyReaSFX.
  3. For portable REAPER, open Options → Show REAPER resource path to locate its folder, then use the resource-path command in the installer guide.

Default manual destination: %APPDATA%\REAPER\Scripts\PsyReaSFX\neural_similarity\.

Portable / manual installer guide ↗

No separate Python or .NET runtime is required. Audio stays local, with no converted copies. First use builds a cancelable embedding cache and HNSW index; a missing or failed component automatically falls back to acoustic search.
