# Beta 14 性能排查与验证范围

用户报告停靠后整个 REAPER 卡顿，左下角来源扫描反复出现，播放指针跳帧。本轮只分析源码并使用隔离测试，不启动或操作用户 REAPER。

| 发现 | 修复 | 验证 |
| --- | --- | --- |
| Watch Folder 从扫描开始计时；大库完成时下一轮可能已经到期 | 改为完成后计时；无变化退避；音频和界面交互优先 | Lua 模拟时钟、播放／录音、交互、取消和完成后的下一次时间 |
| 自动检查每帧做枚举，最后还遍历整个数据库删除未见条目 | 100 ms 间隔、每步 0.5 ms 合作预算／最多 64 次枚举；自动检查不执行删除整理 | 真实扫描函数 + 合成目录计数；不重新导入已有条目，不因自动检查删除收藏 |
| 多种后台工作各有预算，叠加后仍可能拖慢同一次 defer | 通用队列共享 4 ms 合作时间片，轮转避免饿死 | 模拟耗时队列轮转；单次原生 I/O 不可抢占，因此这不是硬实时上限 |
| WebView 未向旧 Lua 后台传递界面操作／窗口缩放信号 | 250 ms 节流活动提示；恢复后台让行机制 | 宿主活动提示测试；重复尺寸通知不增加列表 RPC |
| 锁定运行时的 `WinDockRedraw` 把顶层 REAPER 也纳入子容器重绘拦截 | fork 的 `0.3.9.30-prs.1` 在顶层之前停止安装拦截 | [原生 CI](https://github.com/Psysia/ReaWebAPI/actions/runs/42815278243)：主窗口重绘、子容器保护、重复通知、多标签与清理 |
| 播放指针只随 150 ms 状态快照变化 | 浏览器动画时钟，两次宿主位置之间插值，实际音频由宿主负责 | 浏览器连续帧；无画布重画／列表请求；暂停、速度、跳转、反向、循环、失联停止 |

运行时补丁源码：[`0e0dbf55074f4ea39a8931d7e9cee443e82c69ff`](https://github.com/Psysia/ReaWebAPI/commit/0e0dbf55074f4ea39a8931d7e9cee443e82c69ff)。上游基线 `f3d83ee333a5df0f1242b20efc706ce5a893dabf`；修改范围不涉及 DSP、音频线程或公共 API。自动镜像分支和上游标签保持原样，应用采用独立的补丁发布和 SHA-256 锁。

后续上游候选由 `tools/reawebapi-fork/check_dock_compatibility.py` 针对对应源码编译 Win32 行为测试；失败或实现未知时保留兼容版本，输出具体报告。测试使用自身进程创建的屏幕外窗口，不操作 REAPER。

仍需用户环境验收：浮动／停靠同一工程对照、拖动 Docker 高度、切换其他 Docker 标签后回来、最小化恢复、真实音频与大型磁盘库。慢速／离线网络盘的单次系统调用可能超出合作预算；没有实测数据时不承诺具体帧率提升。
