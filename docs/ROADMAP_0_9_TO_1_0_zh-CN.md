## 0.9：高级检索、频谱分析、相似声音和 DSP

0.9 是下一条正式功能线。四个模块可以在内部并行设计和分阶段验收，但不为了
内部阶段强行拆成大量只有少量变化的公开版本。

### 高级检索：UCS 自动分类与目录

#### 目标

- 随程序提供有明确版本和来源记录的 UCS 分类数据；首个目标基线为官方
  **UCS 8.2.1**。
- 在左侧导航增加独立的虚拟 **UCS 目录**，按
  `Category → SubCategory → CatID` 展开并立即筛选素材。
- UCS 目录只建立索引和分类视图，不移动、复制或重命名任何源音频，也不改变
  用户原有的逻辑音效库与实体目录结构。
- 新素材导入时自动分析文件名和已有元数据；维护页可对现有音效库执行可取消、
  可恢复的分帧分类扫描。
- 搜索框提供 UCS Category、SubCategory、CatID、说明词和 Synonyms 的候选提示；
  中英文模式显示对应的分类名称和关键词。

#### 分类优先级

1. 文件名开头存在合法、大小写正确的 CatID 时，按 UCS 结构精确识别。
2. 文件已有 CatID、Category、SubCategory 等可靠元数据时，进行字段校验和映射。
3. 文件名、Description、Keywords 与 UCS 分类名称、说明词和同义词进行可解释的
   关键词评分，给出一个或多个候选。
4. 无法可靠判断或多个结果接近时标记为“待确认”，不静默写成唯一分类。

#### 用户控制与数据安全

- 明确区分“精确识别”“高置信候选”“待确认”“未分类”。
- 批量应用前提供数量、目标分类、冲突和未分类预览；支持取消与撤销。
- 用户手动分类和自定义关键词优先于自动结果，后续重扫不得覆盖人工选择。
- 默认只把分类结果写入 PsyReaSFX 自己的数据库；是否回写文件元数据必须由用户
  单独开启并确认，0.9 首版不自动重命名文件。
- 保存 UCS 数据版本和分类器版本；规则升级时可以只重算自动结果，不破坏人工结果。
- 分类任务继续遵守 50 万条容量标准：分帧扫描、进度可见、可取消、异常后可恢复，
  搜索提示不得在输入时全量遍历目录。

#### UCS 数据来源

- 使用 [UCS 官方公开资源](https://universalcategorysystem.com/) 作为唯一规范来源，
  保留版本号、来源地址、发布日期和 Public Domain 说明。
- 基础字段至少包括 `Category`、`SubCategory`、`CatID`、`CatShort`、
  `Explanations`、`Synonyms`；翻译字段与自定义关键词分层保存。
- 官方表不直接与用户自定义词库混写，升级 UCS 数据时不得覆盖用户扩展。

自然语言语义检索已进入独立开发阶段，不与“查找相似声音”混用。第一版支持
DeepSeek、OpenAI 和 OpenAI-compatible Chat Completions：由 API 生成双语检索计划，
本地有界召回最多 120 条候选，再只发送候选文本元数据进行语义重排；不上传音频、
完整路径或完整素材目录，API Key 使用 Windows DPAPI 保存。后续再加入本地音频—文本
embedding，使缺少有效文件名和描述的素材也能参与语义检索。相关度排序、OR 与正则
仍作为独立候选项。

## 1.0 Stable：完整稳定发布与长期维护体系

- 冻结并完整验收 0.9 的正式功能范围。
- 完成真实 REAPER、声卡、DPI、SWS、FFmpeg、移动盘、映射盘和 UNC 测试矩阵。
- 以真实 50,000 文件交互测试和 500,000 条容量门槛作为发布依据。
- 冻结数据格式和迁移承诺，验证从 0.7/0.8/0.9 升级、备份、恢复与回退。
- Lua 与 Desktop 使用同一份权威功能对照表；Desktop 在 Lua 功能冻结后统一同步，
  不再按每个 Lua 小修版本重复移植。
- 建立长期支持规则：版本周期、问题等级、兼容范围、发布签名/校验、更新日志、
  ReaPack 历史版本和稳定版回退入口。

## 当前执行顺序

1. 在 `beta/0.9.x` 完成 UCS 官方目录、精确分类、虚拟目录、批量分类与搜索提示。
2. 完成 0.9 频谱分析、相似声音和 DSP 的需求冻结、实现与验收。
3. 持续执行真实环境和大型素材库验收；稳定性修复按需回移 0.8.x 主分支。
4. 冻结并验收完整 0.9 功能范围，再发布公开版本。
5. 同步 Desktop，并完成 1.0 Stable 发布门槛。
