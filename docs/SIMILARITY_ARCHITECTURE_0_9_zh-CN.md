# PsyReaSFX 0.9 相似声音架构

更新日期：2026-09-14  
状态：0.9.0 Beta 4 第一阶段已实现

## 1. 产品边界

相似声音必须比较音频内容，不能把文件名、UCS 分类或用户元数据相似冒充为
声音相似。Beta 4 的入口位于素材右键菜单和下方预览区“更多操作”，用户可以选择：

- 在当前结果中分析：尊重当前库、目录、集合和搜索范围；
- 在全部音效库中分析：清除列表条件并在完整索引中比较。

任务不修改、移动、重命名或回写源音频。结果最多保留 200 条，以固定的相似度
降序显示；参考素材本身不进入结果。

## 2. 特征模型

每个素材从 2,048 点波形与 REAPER 官方频谱峰值附加块提取 15 个归一化特征：

1. 对数时长；
2. 平均包络、RMS 包络与峰值；
3. 起音位置与时间能量重心；
4. 动态离散度、相邻包络变化与静音比例；
5. 对数频谱重心；
6. 低频、中频、高频能量比例；
7. tonality；
8. 频谱数据可用标记。

距离使用有权重的归一化欧氏距离。时长、包络、起音、动态、频谱与音调性分别
组成可解释分组，结果行显示差异最小的两个分组，例如“包络、频谱”。如果宿主或
媒体格式不提供频谱附加块，比较会自动只使用时间域特征并重新归一化权重，不会把
缺失频谱误算成零频谱。

## 3. 缓存格式

缓存位于：

```text
<REAPER Resource Path>/Scripts/PsyReaSFX/similarity_features_v1.tsv
```

每条记录只包含：

```text
16 字符双 FNV 签名<TAB>30 字符量化特征
```

签名同时覆盖规范路径、文件大小、索引时长与算法版本。路径或内容尺寸变化会自然
失效；两个独立 32-bit FNV-1a 组合成 64-bit 标识，降低 50 万条目录中的碰撞风险。
15 个特征各量化为一个字节，最大误差不超过 `1/255`。50 万条有效记录的纯载荷约
22.89 MiB，不保存完整路径。缓存是可重建数据，可在波形设置中清空。

## 4. 调度与交互

- 缓存不参与启动快路，仅在第一次相似检索时按帧延迟读取；
- 每帧缓存读取和候选比较受 3 ms 时间预算限制；
- 缺失特征通过现有波形作业协调器逐个请求，不向队列一次塞入整个素材库；
- RWF4 波形缓存与相似特征缓存复用，但内存波形仍受 180 项 LRU 上限约束；
- 进度条显示已检查、新分析、缓存命中和失败数量，任务可随时取消；
- 分析期间阻止扫描、预缓存、来源重定位与 Transfer 等冲突任务；Watch Folder
  自动静默等待；
- 只保存固定 200 条最佳候选，候选暂存达到 400 条时排序截断，避免结果内存随
  目录规模线性增长。

## 5. 容量与回归门槛

自动测试覆盖：

- 完全不同文件名但相同波形必须得到 100% 内容相似度；
- 时长、起音、包络和频谱明显不同的素材必须显著降分；
- 量化往返误差不得超过 `1/255`；
- 生成 500,000 个真实格式签名时不得碰撞；
- 500,000 条固定记录载荷不得超过 25 MiB；
- 新模块不得直接写共享状态，也不得越过 Host 适配边界。

真实 REAPER 验收仍需覆盖长文件、压缩格式、无频谱附加块、多声道、移动盘离线、
取消后重试以及 50,000 个真实音频的首次分析耗时。Beta 4 不宣称为机器学习语义
搜索，也不使用文件名或标签作为相似度补偿。
