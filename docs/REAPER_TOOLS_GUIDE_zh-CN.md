# Psysia REAPER 工具手册

面向声音设计、轨道管理、渲染、显示与工程操作的实用 ReaScript 集合。

[英文版](./REAPER_TOOLS_GUIDE_en-US.md)

## 安装

### ReaPack

在 `扩展 → ReaPack → 导入仓库...` 中添加：

```text
https://raw.githubusercontent.com/Psysia/PsyReaSFX/main/index.xml
```

随后执行 `扩展 → ReaPack → 同步软件包`。

### 手动安装

实用脚本位于 `Scripts/Psysia/`。将需要的 `.lua` 文件复制到 REAPER 的 Scripts 目录，再通过 `Actions → Show action list → New action → Load ReaScript...` 加载。

## 渲染

### 创建文件夹区域与渲染矩阵 · 2.6

根据当前素材或轨道选择创建、更新 Region。v2.6 明确按“实际涉及多少条源轨道”决定行为：

- **只有 1 条源轨道：** Region 名直接使用这条轨道自己的名称，Region Render Matrix 也直接勾这条轨道；无论外面嵌套多少层 Folder，都不继承父级。
- **涉及 2 条及以上源轨道：** 才寻找最近公共父级，并用该公共父级同时负责命名和 Matrix；如果没有共同父级，则组合源轨道名称并分别勾选源轨道。
- Matrix 写入后会立即读回检查。若 REAPER 实际没有按预期勾选，会直接提示“预期/实际”轨道，而不是静默留下空矩阵。
- 仍支持多个逻辑 Region 使用相同时间范围。

### 智能尾音渲染面板 · 1.1

集中配置 REAPER 原生 Render Tail 与结尾静音裁切。适合混响、Delay 或长尾素材，避免渲染边界直接截断尾音。

脚本只改变渲染时间范围相关设置，不会修改工程路由。

### 打开渲染窗口并应用自动尾音 · 1.0

先将已保存的自动尾音设置写入当前工程，再打开 REAPER 原生 Render 窗口。适合作为启用智能尾音工作流后的日常渲染入口。

## 轨道管理

### 按最早素材位置排序轨道 · 1.4

在最近共同层级上排序，不再单独移动 Folder 父轨。

- 普通轨道按单轨单元移动。
- Folder 会连同完整子树一起移动。
- 存在选中素材时优先按选中素材判断排序位置。
- 未参与排序的同级单元保持原来的槽位。

### 从选中轨道创建文件夹并挂载 Pro-L 2 · 1.1

在连续的同级轨道或已有同级 Folder 上方建立新的 `Folder Bus`，保留完整子树，并在新父轨挂载 `Pro-L 2`。

选择已有 Folder 时，只选父轨即可。跨父级或不连续选择会被拒绝，避免误包入无关轨道。

### 统一轮换选中文件夹折叠状态 · 1.4

单层 Folder 使用：

```text
完全展开 ↔ 完全折叠
```

存在嵌套时使用：

```text
深度完全展开
→ 收起子文件夹内轨道
→ 仅子文件夹小折叠
→ 完全折叠
→ 深度完全展开
```

第三层会保持外层选中 Folder 展开，只让内部子 Folder 进入小折叠。

### 根据父级文件夹名重命名选中轨道 · 1.0

只使用**最近一级父文件夹**名称，并按轨道从上到下编号：

```text
父级名_01
父级名_02
父级名_03
```

不同父级分别从 `_01` 开始。没有已命名直接父级的轨道会跳过。

## 素材编辑

### 移除选中素材间隙 · 1.0

按当前顺序移动选中素材，让后一个素材紧接前一个素材结束位置。

### 拆分选中素材到新轨道 · 1.0

保持时间位置不变，将选中素材移动到新建轨道。存在 Take 名称时，会用 Take 名称命名新轨道。

### 原位反转选中素材 · 1.0

先执行 REAPER 的“反转到新 Take”，再裁切到当前 Take，从而得到近似原位反转效果，并保持一次撤销即可恢复。

## 工程与显示

### 打开全部子工程 · 1.0

扫描当前工程引用的子工程，在新的工程标签页中打开，并继续递归查找下一级子工程。已经打开的工程不会重复打开，缺失文件会统一提示。

SWS 不是必需依赖；安装后可用于更准确地解析部分子工程路径。

### 切换 LUFS-M 与频谱图 · 1.1

在 REAPER 的 LUFS-M 频谱峰值显示与普通频谱图之间切换。脚本会动态解析当前语言环境下的 Action 名称，并缓存经过验证的 Command ID。

### 视频素材轨道名覆盖显示 · 1.9

这是一个可开关的 Arrange View 覆盖层。v1.6 改为显示每个视频 Item 所在轨道的当前轨道名称，因此直接修改 Track Name 后，覆盖文字会自动同步更新；Play 和 Record 期间仍然自动隐藏。

- 显示内容直接来自当前 REAPER 轨道名称，不再使用源视频文件名或扩展名作为标签。
- 字号会根据当前可见 Item 的宽度和高度自动适配，横向或纵向缩放时实时变化。
- 整个多行文字块会在 REAPER 原有 Item 顶部标题/图标区域下方进行水平、垂直整体居中。
- 轨道名会完整换成多行显示，不再使用省略号截断；v1.4 会更早触发换行，并在空间不足时临时突破设置中的首选最小字号，最低缩到约 5px，以尽量避免名称直接消失。
- 常见视频扩展名以及 VIDEO 类型媒体源都会被识别。

通过配套的 **视频素材覆盖显示设置** Action，可以从 Windows 已安装字体下拉菜单中选择字体，并设置最小字号、最大字号和字重。默认字体为 **Microsoft YaHei UI（微软雅黑 UI）**。v1.8 改为先用 Windows GDI 直接绘制 UTF-8 轨道名，再通过 LICE/Composite 合成，修复此前中文/CJK 字符可能完全不显示的问题。

两个视频覆盖模式共用同一套设置，并且自动互斥：当前模式开启时，直接运行另一个 Action 就会立即切换，不需要先手动关闭。

### 视频素材源文件名覆盖显示 · 1.0

使用与轨道名模式相同的绘制与多行自适应逻辑，但显示内容改为视频的**源文件名**，并继续隐藏最后的文件扩展名。启动此 Action 会自动停止轨道名覆盖并接管；再次运行轨道名 Action 即可切回。

两个模式共用 **视频素材覆盖显示设置**，包括已安装字体下拉菜单、字号和字重。

该覆盖层依赖 **js_ReaScriptAPI**。

## 依赖

大部分工具只使用 REAPER 原生 ReaScript API。

- **SWS Extension**：仅“打开全部子工程”可选使用，用于提高部分路径解析准确性。
- **Pro-L 2**：仅“从选中轨道创建文件夹并挂载 Pro-L 2”需要。
- **js_ReaScriptAPI**：视频素材轨道名覆盖显示需要。
- **ReaPack**：只负责安装与更新，不是脚本运行时依赖。
