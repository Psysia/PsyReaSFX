# PsyReaSFX 0.9 AI 语义搜索架构

更新日期：2026-09-21

状态：0.9.0 Beta 7.8 已支持大型素材库快速召回与纯本地分页排序

## 定位

AI 语义搜索是“以文字描述找声音”的独立工作流，不属于“以参考音频找相似声音”的声学/神经相似度系统。AI 只负责理解描述和扩展检索词；素材召回、排序与分页保持在本地。

## 第一版流程

1. 用户输入自然语言声音描述。
2. DeepSeek、OpenAI 或 OpenAI-compatible Chat Completions 将描述转换为有界的中英文正向词、排除词和声音概念。
3. Lua 将扩展词预编译一次，在当前范围内逐帧扫描；每条素材先经过合并文本粗筛，只有命中项才执行字段加权评分，并使用固定 Top-2400 堆保存可分页候选。
4. Lua 按本地召回分稳定排序，并把前 120 条显示到独立结果视图。
5. 用户点击“继续加载下一批 120 条”时，Lua 直接从已有候选池追加结果，不再调用 API。

本地召回分的字段权重依次为：文件名 8、Keywords 7、Description 6、UCS Category 6、SubCategory 5、CatID 4、音效库 2、路径 1；每命中一个正向扩展词另加 0.75，命中排除词扣 12。最终显示顺序按本地召回分从高到低排列，同分时按路径稳定排序；页面按这一固定顺序每 120 条切分。

## 支持的接口

- DeepSeek：`https://api.deepseek.com/chat/completions`，默认 `deepseek-flash`，可选 `deepseek-v4-pro`；旧 `deepseek-chat` / `deepseek-reasoner` 配置自动迁移。
- OpenAI Chat Completions。
- 自定义 OpenAI-compatible Chat Completions 地址和模型。
- 远程服务强制 HTTPS；仅环回地址允许 HTTP，便于连接本机模型服务。

## 凭据与隐私

- API Key 不进入 Lua 普通配置、Git、日志或数据备份。
- Windows PowerShell bridge 使用当前用户 DPAPI 加密密钥。
- Lua 启动时清理可能由异常中断遗留的固定明文临时文件。
- Key 不出现在进程命令行；bridge 只从加密文件解密到当前进程内存。
- 只上传用户输入的自然语言描述；不上传音频、素材文件名、元数据、完整文件路径或素材目录。
- 恢复出厂会删除保存的 API Key。

## 性能边界

- 本地召回使用“合并文本粗筛 → 命中项字段加权评分”的两级流程，并复用已经存在的普通搜索文本缓存。
- 查询词每次搜索只规范化和拆分一次；10 万条合成素材容量回归测试约 0.6 秒完成。
- 召回仍逐帧执行并遵守时间预算，避免一次遍历大型目录阻塞界面。
- 本地候选池固定最多 2400 条，生成检索计划后不再调用 API。
- 用户浏览完当前结果后可按需继续加载下一批，翻页只读取内存中的本地候选池，基本即时且不产生额外 API 调用或费用。
- AI 任务通过现有 `Jobs` 协调器使用独立的 `ai_semantic_api` 资源，可取消且不会被波形预缓存、索引保存或目录维护长期阻断；搜索启动时保存稳定的素材数组快照。

## 已知边界与后续方向

第一版只能通过 AI 扩展词理解文件名与文本元数据，无法直接听懂音频。后续加入 CLAP 或同类本地音频—文本 embedding 后，文本查询可进一步从本地向量索引召回。
