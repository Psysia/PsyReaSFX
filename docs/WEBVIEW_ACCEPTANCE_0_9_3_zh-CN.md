# PsyReaSFX 0.9.3 Beta 10 功能对照与验收清单

对照基线：旧版 `v0.9.2-beta4` 原生界面及 Beta 8 的共享 Lua 服务。入口主要核对 `src/lua/50_runtime_ui.lua`、`11_ui_workspace.lua`、`13_workspace_tabs.lua`；网页入口对应 `src/web/app.js`、`settings.js`，宿主接口对应 `src/lua/48_webview.lua`。

下面的勾选框供实际验收使用，**留空不代表入口缺失**。本轮已完成代码映射、Lua 宿主回归和浏览器模拟交互；用户已确认 Beta 9 的空格路由正常；本版真实音频续播、跨窗口拖放和真实库长时间操作仍需实机验收。浏览器通过不能代替实际听音、工程插入或文件导出。本轮没有启动额外 REAPER 实例，也没有触发插件扫描。

建议先使用一个空白测试工程和一份临时素材库：包含短/长 WAV、含中文路径、单声道/立体声/多声道、BWF、带封面、可做重复对比的文件。导出到临时目录。备份/重置/移除项目使用临时数据验证。

## 本次反馈优先验收

- [ ] **暂停/继续**：试听中按空格，游标留在暂停点；再按空格从该位置继续。选区、反向和非 1× 速率分别检查；独立停止按钮结束试听。设置 → 常规 → 试听控制选择“停止/重新播放”后重试；输入框仍能打空格，REAPER 主工程不启动。
- [ ] **音效库/文件夹**：显示“音效库 → 来源文件夹 → 子目录”；图标展开、名称筛选，标签靠左对齐。拖目录到库名和任意子目录，都仅给所属库新增来源；展开目录在后台扫描期间也能响应。
- [ ] **波形加载**：连续选择不同素材；已有概览即时出现，详细波形就绪后替换；切回近期素材立即使用缓存。首次无缓存仍取决于文件读取，失败时可以重试。
- [ ] **相似声音**：扫描中发起检索，应出现等待原因且没有 Lua 报错；扫描完自动开始；取消等待不停止扫描。选择“当前结果”后在等待中改变筛选，应取消该等待请求。
- [ ] **右上任务**：原素材箱快捷入口变为任务入口；数量、名称与后台任务一致，可取消等待；左侧和素材右键仍能访问集合。
- [ ] **悬停菜单**：悬停分组约 180 ms 后展开子菜单；移入子菜单保持打开，滑到其他分组切换；靠右/下边缘不裁切，中英文和方向键均正常。
- [ ] **前版回归**：UCS 搜索、紧凑 FX、详情面板滚动、波形选区、拖入 REAPER、Transfer 与设置保存仍可用。

- [ ] **走带与信息层级**：音量常驻播放/循环旁，收起 FX 仍可用；双击回到 0 dB；FX 复位不影响音量。响度在格式信息旁，左侧四行时间框和底部任务栏已移除。
- [ ] **精确选区**：无选区时标题不重复全长；拖出选区后显示时长摘要，悬停查看入出点，点击可输入秒数；切换素材后旧编辑不能应用到新素材。
- [ ] **列设置**：表头右键直接设置显示列、顺序；顶部与表格内重复的布局按钮消失；侧栏/检查器保留各自的展开按钮。
- [ ] **欢迎与启动**：先出现 PsyReaSFX 品牌和加载阶段；准备好立即进入列表，没有人为延时；帮助/诊断包含实际启动耗时。
- [ ] **最小化恢复**：从公共 `PsyReaSFX.lua` 启动后最小化，再运行同一动作应恢复原窗口，后台任务和试听不重启。Windows 浮动窗口在已安装 js_ReaScriptAPI 时注册任务栏入口；停靠后不产生额外任务栏窗口。
- [ ] **AI 密钥与持久化**：保存密钥期间界面仍响应，成功才显示已保存；收藏/历史自动保存期间继续修改，重开后保留全部更改。故障注入与详细边界见[底层复查记录](WEBVIEW_CORE_AUDIT_0_9_3_BETA10_zh-CN.md)。

### 本版更新一次后的入口

从旧版升级时先关闭一次旧 PRS 窗口，再同步 ReaPack 或安装完整包；之后继续运行原来的 `PsyReaSFX.lua` 动作即可。不要单独启动新增的 `PsyReaSFX_Runtime.lua`，它负责后台循环。再次运行公共入口只唤回现有窗口，不触发 REAPER 的终止/新实例选择。任务栏是否合并到 REAPER 图标组由 Windows 设置决定；没有 js_ReaScriptAPI 时，公共入口仍能唤回。

## 导航、音效库与文件夹

原生入口：`draw_sidebar`, `draw_library_manager_popup`, `draw_folder_sidebar`。

音效库是逻辑分组，不是额外创建的磁盘文件夹。每个库可关联多个来源文件夹，来源下面按真实磁盘层级展开子目录。点击库名筛选整个库，点击目录名筛选该目录及其后代，图标只负责展开/折叠。

拖到库内任何层级会给所属库添加来源，不会把新目录搬进被拖到的子目录。拖到工作区空白处时，优先加入当前选择的库；“全部音效库”且未指定目标时，一个目录新建库，多个目录可分别建库或合并。同库已有来源不重复添加；若来源已属于另一个库，沿用原逻辑确认是否改变归属。所有这些操作均不复制或移动源文件。

## 渲染器适配说明

- 原生 UI 的 `surface_style`、`theme_preset`、字体、布局尺寸、列宽、导航可见性，映射为网页主题、字体、行高、面板尺寸和本地工作区偏好。算法、数据文件及处理服务继续复用 Lua。
- 原“封面固定在顶部”改为“封面置于详细信息前”：决定内容顺序，封面随检查器滚动，避免遮挡元数据。
- 原目录悬停级联和根目录/树形切换，映射为常驻文件夹面板：名称筛选根/子目录，文件夹图标展开。操作入口保留，鼠标交互方式调整。
- 原 FX 参数卡和弹出预设，映射为波形上方单行 Pitch/Rate 控制条与悬停级联预设菜单；音量独立常驻走带区；底部高度单独记忆。
- 新增网页工作区偏好“试听控制”：默认暂停/继续，可切回停止/重新播放；独立停止按钮保持结束试听。此项不是新增 Lua 设置字段，宿主参数总数仍为 73。
- `selection_hex` 与网页自定义选区颜色共用同一个保存入口；默认选区使用主题色，不对整段波形铺蓝底。
- 原生帧耗时显示为网页右上方 Lua 后台/宿主更新/帧间隔。网页布局性能仍用浏览器回归测量，不能把宿主帧时间当成浏览器 FPS。
- 空格明确配置当前 ReaWebAPI 窗口：关闭 DAW Space 转发、关闭 Main 快捷键路由、开启键盘捕获；页面在捕获阶段处理单次 Space。用户已确认 Beta 9 的路由正常；本版暂停与继续请按优先验收第一项验证。

源码映射清单：仓库 `tools/webview_parity_inventory.json`。以后新增旧版功能或宿主参数时，应同步更新该清单和相应测试。
