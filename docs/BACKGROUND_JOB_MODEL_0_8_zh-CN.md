# PsyReaSFX 0.8 后台任务模型

## 目标

所有长任务都必须拥有独立代次、取消状态和资源所有权。取消旧任务只能发出取消请求，不能提前释放仍在异步收尾的对象，也不能清除更新代次的状态。

## 资源与并行规则

| 资源 | 任务 | 规则 |
|---|---|---|
| Catalog exclusive | 扫描、导入、Transfer、缺失检查、重复检查、波形预缓存、缓存校验 | 同时只允许一个；Watch Folder 事件只合并为下一次扫描请求 |
| Preview engine | 试听、声道/反向/保留音高重建 | 新代次取消旧代次；旧代次真正退出前仍计入关闭等待 |
| Audio analysis | 响度分析 | 同类任务替换，和 UI 浏览解耦 |
| Drag export | 选区预导出 | 选区或素材变化即取消旧代次 |
| Artwork / waveform reader | 封面发现、波形构建 | 每帧预算执行；单个任务完成后释放资源 |
| Catalog writer | 全量快照、组织、活动、元数据、Region、响度、工程记录 | 所有 SQLite 写入进入同一个后台串行队列；短时间连续组织保存只保留最新快照 |

## 状态

统一状态为：等待、运行、取消中、完成、已取消、失败。每个任务记录唯一 generation、优先级、开始时间、结束时间与错误摘要；只保留最近 64 条完成历史，避免诊断数据无限增长。

## 关闭流程

1. 停止 Watch Folder 和计时器，不再接收新任务。
2. 向所有仍在运行的代次发出取消请求。
3. 等待旧代次异步收尾；Desktop 最长等待五秒并记录超时。
4. 释放试听设备、波形源和其他原生资源。
5. 从 UI 线程捕获最终快照并按顺序保存。
6. 第二次关闭事件才真正退出窗口。

## 自动压力检查

Desktop 自检连续创建 250 个试听代次，验证：

- 上一代会被取消；
- 乱序完成不会清掉当前代次；
- 关闭后拒绝新任务；
- 关闭等待覆盖所有未退出旧代次；
- 不再出现 `CancellationTokenSource has been disposed`。

写入队列自检会连续提交 64 个组织快照，验证调用线程不被 SQLite 同步路径阻塞、最终状态等于最后一次请求，并审计实际写入次数。当前结果为执行 1 次、合并 63 次。
