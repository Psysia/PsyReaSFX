# PsyReaSFX 0.9.3 Beta 16

- 修复后台扫描“取消无效”：取消请求现在设置后台任务标记，播放／交互暂停也不阻塞退出；无新增素材时立即结束，保留已有素材及收藏。
- 优化来源检查：首次核对文件名建立目录基线，随后跳过未变化目录，独立检查子目录；自动分析仅处理新增素材。保留约 30 分钟的文件名复核，以及目录状态不可用时的回退。
- 任务详情分别显示“已核对文件名”“新增”“跳过未变化目录”和取消状态。取消当前检查不会关闭自动监视，下一轮按设置的间隔执行。

更新 ReaPack 中的 **PsyReaSFX 0.9.3-beta16**，关闭并重新打开 PRS。运行库继续使用 **0.3.9.30-beta3**（实际 `0.3.9.30-prs.2`）；已安装该运行库的用户无需再次更新 DLL。
