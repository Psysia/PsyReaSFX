## PsyReaSFX Lua 0.8.5

本次版本修复已完成建库后，启动仍可能误判为中断扫描并反复从根目录重新扫描的问题。

### 修改内容

- Watch Folder 后台检查不再创建启动恢复点，无论是否显示完整进度都不会冒充异常中断任务。
- 恢复点升级为 v3，增加明确的恢复许可和更新时间；0.8.4 及更早版本留下的含混检查点会自动作废。
- 仅保留七天内、由前台扫描产生的有效恢复点；完成任务后会在索引持久化成功时清理。
- 用户关闭 PsyReaSFX 主窗口会被视为正常退出并清除恢复状态，真正异常终止仍可在下次启动恢复。
- 补充持久化、Watch Folder 与主窗口关闭行为的回归检查，并通过 50 万条结果、缓存和持久化容量测试。

### 安装

- ReaPack 用户刷新仓库后可直接更新到 `0.8.5`。
- 手动安装用户可下载 ZIP，将脚本和 `assets` 目录保持原结构放入 REAPER Scripts 目录。
