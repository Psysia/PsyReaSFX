# PsyReaSFX 0.9.2 Beta 4 (pre-release)

Replaces Beta 3 and makes the frame-timing diagnostics more specific. **The stable channel stays at 0.9.1.** In ReaPack enable pre-releases, synchronize, install `0.9.2-beta4` under **Versions**, then close the old window and rerun PsyReaSFX. The About page should read `0.9.2 Beta 4`.

取代 Beta 3，并让帧耗时诊断更具体。**稳定通道仍为 0.9.1。** 在 ReaPack 中启用预发布并同步后，于 **Versions** 安装 `0.9.2-beta4`，关闭旧窗口后重新运行。关于页应显示 `0.9.2 Beta 4`。

## What changed since Beta 3 / 相对 Beta 3 的变化

- Settings → Maintenance → "show frame timing" and **Copy diagnostics** now include a `bg:` line (overlay) / "Background work" line (diagnostics) listing how many milliseconds each background job takes per frame, next to the drawing sections. / “显示帧耗时”浮层新增 `bg:` 一行，“复制诊断信息”新增 “Background work” 一行，列出每个后台任务每帧占用的毫秒数，与绘制分段并列。

Everything else is unchanged from Beta 3. / 其余与 Beta 3 相同。
