# PsyReaSFX 0.9.a WebView Beta 5

ReaPack 版本 `0.9.3-beta5`，Windows x64。

本轮对照 Lua 界面的操作入口，补齐 WebView 未接入的状态、设置和管理功能。

- 试听后的文字和小波形颜色、独立开关、自定义颜色、恢复／清除会话高亮，以及小波形播放位置线。
- 标记、工作流状态、批量收藏、堆叠插入、完整可选列及列顺序／列宽复位。
- 文件夹层级、保存搜索、工作流筛选；输入搜索词保留当前文件夹或集合范围。
- 音效库、来源、集合管理，工程素材箱绑定、封面指定／重新发现／清除。
- 批量元数据编辑，仅应用勾选字段；选择或后台数据变化时拒绝旧编辑内容，避免覆盖。
- 立体声左／右／单声道与多声道选择，响度、瞬态、UCS 候选确认和分类预览。
- 频谱着色、高精度详情波形、擦播、缩放平移、Region，以及可折叠的高级 Transfer 设置。
- AI 预设删除和连接测试错误反馈、备份与缓存维护、诊断复制、快捷键。

浏览器回归覆盖五十万条有界列表、侧栏切换不挤压底部波形、播放状态、设置和严格 JSON 传输；Lua 回归覆盖参数校验、批量编辑冲突、批量收藏、声道和搜索范围。独立 REAPER + 外部 ReaWebAPI 0.3.9.29 中验证导入、真实试听高亮、元数据、插入和实际 WAV 导出。

文件夹拖入与拖入 REAPER 的处理路径已接入；完整跨窗口鼠标拖放、不同缩放比例和多显示器场景仍待实机验收。此版本不宣称全部交互已完成验收。完整对照见 [功能记录](../WEBVIEW_PARITY_0_9_3_zh-CN.md)。

在 ReaPack 同步并更新主脚本，关闭旧 PsyReaSFX 窗口后重新运行。已有兼容 ReaWebAPI 可继续使用。
