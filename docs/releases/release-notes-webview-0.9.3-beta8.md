# PsyReaSFX WebView Beta 8 — 波形与交互修复

本版针对 Beta 7 实测反馈修复波形、导航和试听区交互。

- **波形**：可见列表行全部加入后台缓存队列，避免后排一直空白；后台更新不再误拒绝同一文件的点击；读取失败可直接重试。高声道数的波形响应限制在原生消息容量内。
- **导航**：左侧图标切换音效库／浏览／收藏／历史／UCS／集合面板。文件夹箭头展开下级，名称点击筛选；UCS 字号统一；设置保留右上角入口。
- **试听区**：取消整段波形的蓝色填充，默认跟随主题，设置 → 外观与布局可自定义选区颜色。FX 独立成行，小窗口内滚动；播放按钮始终可见。
- **元数据与响度**：封面随内容滚动，标签页固定；LUFS／True Peak 读数放到波形下方，提供重新分析入口，显示项目沿用响度设置。
- **相似声音**：可选当前结果或全部库，显示首次建立缓存的进度并可取消。兼容已安装的控制台版分析组件，后台运行不弹黑窗；组件不可用时沿用内置声学分析。

验证包括 Lua 缓存／选择／文件夹回归、50 万条模拟目录的浏览器交互、900×620 至 1600×1000 的 FX 布局、隐藏子进程的控制台句柄与 Unicode 参数传递、已安装神经组件的能力握手，以及离线安装和回滚。截图使用模拟素材库。

通过 ReaPack 启用预发布后同步，选择 **0.9.3-beta8**；也可下载完整 ZIP 并阅读包内安装说明。旧版与稳定版保留回退入口，不要求删除波形缓存。
