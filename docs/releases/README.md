# Release notes archive / 发布说明归档

The project root keeps only the current release summary. Historical release drafts are preserved here, unchanged; their version numbers and links refer to their original release.

项目根目录仅保留当前版本摘要，历史发布说明集中在此存档，内容不删减。其中的版本号和链接对应当时版本，不代表最新版。

- [Published releases / 正式发布页](https://github.com/Psysia/PsyReaSFX/releases)
- [Changelog / English](../CHANGELOG_en-US.md)
- [完整更新日志 / 简体中文](../CHANGELOG_zh-CN.md)

Future published-note sources belong in this folder. Temporary release/PR drafts should use the ignored `dist/` directory, not the repository root.

后续需保留的发布说明放入此目录；临时 Release / PR 草稿放在不提交的 `dist/` 中，避免再次堆积到主页文件列表。
