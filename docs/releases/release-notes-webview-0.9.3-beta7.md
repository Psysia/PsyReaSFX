# PsyReaSFX WebView Beta 7 — 交互与设置重写

修复设置回车误关闭、编辑内容被状态刷新覆盖、重复分页和菜单入口不顺畅的问题。以 Lua 0.9.2 Beta 4 为功能基准，保留暗色波形布局、全宽试听区及默认折叠的 FX。

- 菜单、侧栏导航、筛选状态和九类设置重新组织；设置支持搜索、草稿、应用、放弃及失败重试。
- 集合、搜索、标签页和 Region 使用网页命名窗口；元数据长字段有完整读取和覆盖保护。
- Transfer 参数在刷新与面板切换后保留；输出目录操作和逐任务取消有明确入口。
- 列表请求合并、过期响应丢弃、波形静态绘制缓存，减少重复工作；加载期间设置仍可打开。
- 补齐中英文词条与 ReaPack 前端模块清单。

验证：29 项旧版 Lua 回归、WebView 无界面宿主、50 万条模拟目录浏览器交互、翻译检查及离线安装／回滚测试通过。附图使用模拟素材库。

**原生 REAPER 验收仍未完成。** 隔离测试在 WebUI 探针运行前触发第三方插件扫描，期间出现 REAPER 读取错误；崩溃模块尚未确定。测试进程已结束，用户原有 REAPER 正常。本候选不宣称已经解决该原生崩溃，也不作为稳定版本。

下载完整 ZIP 后查看包内 `README.txt`。捆绑的 ReaWebAPI 0.3.9.30 仍是待原生验收的候选；Beta 安装入口用于隔离的 REAPER 资源目录，安装器保留已有外部扩展。主分支的 ReaPack 清单需要合并后才会提供本版更新。
