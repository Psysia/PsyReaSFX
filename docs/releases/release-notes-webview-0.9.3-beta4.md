# PsyReaSFX 0.9.a WebView Beta 4

ReaPack 版本为 `0.9.3-beta4`，面向 Windows x64。

- 修复素材选择消息包含 undefined 时被 ReaWebAPI 拒绝的问题，统一在发送前转换为 JSON 数据。
- 修复增量日志更新素材后路径缓存失效却未重新计算的问题，恢复筛选和波形缓存访问。
- 设置面板点击后立即显示，提供读取状态、失败原因和重试入口。
- 回归测试覆盖严格 JSON 传输下的素材选择、设置、Region、交付参数、播放控制和标签入口，以及增量更新后的路径、筛选和波形缓存。

在 ReaPack 同步并更新主脚本，关闭旧 PsyReaSFX 窗口后重新运行。继续使用已有兼容的 ReaWebAPI。

本轮检查覆盖上述主要入口及现有自动化回归。完整功能迁移、大型真实素材库性能和原生音频操作的全面验收仍在进行。
