# PsyReaSFX 0.9 频谱分析架构

更新日期：2026-09-11  
状态：Beta 3 开发中，第一阶段需求已冻结

## 第一阶段目标

第一阶段在下方当前素材的大波形中增加“频谱峰值着色”。它用于快速判断每个时间片的主导频率和音调性，同时保持现有波形选区、Region、播放指针、缩放、平移和独立声道布局不变。

这不是把普通波形伪装成完整 FFT 频谱图。数据来自 REAPER 官方 `PCM_Source_GetPeaks` 的 `extra_type = 115 ('s')` 频谱附加块：低 15 位为频率，随后 14 位为 tonality。当前阶段显示每个时间片中峰值幅度所在声道的主导频率；后续如果需要完整的时频能量矩阵，将作为独立阶段评估，不复用“频谱峰值”名称。

## 已冻结交互

- 默认关闭；可在 `设置 → 波形` 或预览区“更多操作”中开启。
- 只对当前素材的下方大波形按需分析，不扫描整个音效库，也不改变列表缩略波形。
- 开启后先复用已有普通波形作为占位；频谱数据准备完成后原位切换着色，不弹出模态进度窗口。
- 颜色按 20 Hz–20 kHz 对数刻度由低频蓝紫、低中频青色、中高频绿色过渡到高频橙色；tonality 决定频谱颜色相对普通波形色的权重。
- 选区、播放指针、Region 和声道选中/弱化仍具有更高的交互语义，不因频谱着色改变命中区域。

## 缓存与性能

- 普通列表波形继续使用现有 RWF2；独立声道波形继续兼容 RWF3。
- 带频谱数据的缓存使用 RWF4，并在缓存键加入 `spectral-rwf4`，因此不会把旧缓存误读为频谱数据，也不要求用户清空原缓存。
- RWF4 在每点、每声道 16-bit 幅度之后，为每个时间点保存 16-bit 频率和 16-bit tonality；4096 点缓存只增加 16 KiB。
- 读取仍沿用现有跨帧构建、六次有界重试和一次媒体源重开生命周期。频谱附加块不可用时保留普通波形，不把素材标记为损坏。
- 内存仍受现有 LRU 上限控制；频谱缓存与普通缓存是两个独立键，关闭频谱后不会维持新的后台分析队列。

## 第一阶段验收

- REAPER 返回频谱附加块时能正确解出频率与 tonality，同时保留幅度和独立声道波形。
- RWF4 的幅度、频率、tonality 可以写入、重新读取并通过缓存完整性检查。
- 无附加频谱能力、暂时空峰值、媒体源重开和最终失败均保持现有有界行为，不泄漏媒体源。
- 频谱关闭时，不产生频谱缓存任务；列表滚动和 50 万条目录容量测试不增加逐素材工作。
