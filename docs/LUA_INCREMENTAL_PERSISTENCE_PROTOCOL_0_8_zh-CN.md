# Lua 素材增量持久化协议

记录日期：2026-09-02

## 目标

在 500,000 条素材目录中，收藏、工作流、试听次数、元数据和封面等少量变化不再
触发完整 `index_v3.tsv` 重写，同时保持原子快照、备份恢复和未来版本只读保护。

## 安全约束

1. 基础快照拥有单调递增的 `generation`；
2. 增量日志必须声明它所属的基础快照代次；
3. 代次不一致的日志绝不重放，防止压缩后的旧日志覆盖新快照；
4. 每条记录带校验码，整个文件必须以完整换行结束；
5. 解码器先验证完整日志，再向目录状态应用记录，禁止部分重放；
6. 日志压缩先原子提交新快照，再清除旧代次日志；中断后旧日志因代次不匹配自动失效；
7. 结构性扫描、来源删除和重定位在完成脏记录接入前继续走完整快照，不冒险推断删除范围。
